# Personal-Boundary---Mini-Compiler

## 📌 Overview
This project implements a basic compiler using:
- Lexical Analysis (Lexer)
- Recursive Descent Parser

## ⚙️ Features
- Tokenization of input code
- Syntax parsing using grammar rules
- Error handling for invalid syntax

## 🛠️ Technologies
- C++
- Compiler Design Concepts

## 📂 Files
- lexer.cpp → Tokenization logic
- parser.cpp → Parsing logic
- tokens.h → Token definitions
- main.cpp → Driver code
